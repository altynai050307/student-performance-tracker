# Студенттердің үлгерімін есепке алу жүйесі

Бұл СОӨЖ аясында әзірленген Flask негізіндегі веб-қосымша. 
Жобада GitHub Actions арқылы CI/CD-конвейері (Build & Test) іске қосылған.

## Жобаны жергілікті іске қосу:
1. Тәуелділіктерді орнату: `pip install -r requirements.txt`
2. Қосымшаны іске қосу: `python app.py`
3. Тесттерді орындау: `pytest`
